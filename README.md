# Eko-Szepty-Ostatni-Straznik
Wcielasz się w małego, świecącego duszka lasu w świecie, który został skażony przez rozrastającą się, mechaniczną czarną mazię (symbol pożerającej naturę technologii). Twoim zadaniem jest przywrócenie równowagi poprzez oczyszczanie terenu, sadzenie magicznej roślinności i manewrowanie między patrolującymi teren mechanicznymi maszynami.
